General strategy

  1. Underline what they're asking for. Many mistakes come from solving for x when the question asks for 2x, x + y, or the area instead of the side.
  2. Questions get harder as you go through a module. Move quickly and carefully through the early ones, and save time for the last 5–6.
  3. Plug in. If the choices are numbers, try them in the equation. If the question uses variables, pick easy numbers (like x = 2) and test each choice.
  4. Use the calculator smartly, but don't type everything. Mental math is faster for simple steps.
  5. About 95 seconds per question. If you're stuck after 2 minutes, guess, mark it, and come back.

Student-produced response (typed answers)

  • You can type a fraction (7/2) or a decimal (3.5). Up to 5 characters for a positive answer, 6 for a negative one (the minus sign counts).
  • No mixed numbers: type 3 1/2 as 7/2 or 3.5.
  • Repeating decimals: fill the space, e.g., 2/3 as .6666 or .6667 (or just type 2/3).
  • Don't type symbols like %, $, commas, or units.
  • If more than one answer is correct, enter just one.

Desmos tricks that save time

  • Solve any equation by graphing: type the left side as y = … and the right side as y = …; tap the intersection point. The x-value is the solution.
  • Systems of equations: type both equations as they are (Desmos handles 2x + 3y = 12). Tap the intersection.
  • Quadratics: graph y = x² − 6x + 5 and tap to see the vertex, the x-intercepts (zeros), and the y-intercept.
  • Check equivalent expressions: graph the original and each choice; the matching one draws exactly on top.
  • Sliders for unknown constants: type y = x² − 6x + c and click "add slider" for c. Slide until the graph touches the x-axis once.
  • Regression: put data in a table, then type y₁ ~ mx₁ + b to get the line of best fit.

Practice with the free Desmos calculator so it feels familiar on test day.

1. Algebra (≈35%)

  • Slope m = (y₂ − y₁)/(x₂ − x₁). Slope-intercept: y = mx + b (b is the y-intercept). Point-slope: y − y₁ = m(x − x₁).
  • Parallel lines have equal slopes. Perpendicular slopes are negative reciprocals (2/3 → −3/2).
  • In word problems, the slope is the rate (per hour, per item), and the y-intercept is the starting value or fixed fee.
  • Systems: use substitution or elimination. No solution = parallel lines (same slope, different intercept). Infinitely many = same line.
  • Inequalities: flip the sign when you multiply or divide by a negative. "At most" = ≤, "at least" = ≥.
Example: solving a linear equation

If 4(x − 3) = 2x + 10, what is x?

Show solution

Distribute: 4x − 12 = 2x + 10. Subtract 2x: 2x − 12 = 10. Add 12: 2x = 22. x = 11. Check: 4(8) = 32 and 2(11) + 10 = 32 ✓.

Example: elimination

3x + 2y = 16 and x − 2y = 0. Find x and y.

Show solution

Add the equations; the y terms cancel: 4x = 16, so x = 4. Then 4 − 2y = 0, so y = 2. Check: 3(4) + 2(2) = 16 ✓.

Example: no solution

For what value of k does the system y = 3x + 5 and y = kx − 2 have no solution?

Show solution

No solution means parallel lines: same slope, different intercepts. The intercepts (5 and −2) already differ, so k = 3.

2. Advanced Math (≈32.5%)

  • Factoring patterns: x² − a² = (x − a)(x + a); (a + b)² = a² + 2ab + b²; (a − b)² = a² − 2ab + b².
  • Quadratic formula: x = (−b ± √(b² − 4ac)) / 2a. The discriminant b² − 4ac: positive → 2 real solutions, zero → 1, negative → none.
  • Vertex of y = ax² + bx + c is at x = −b/(2a), halfway between the zeros. Vertex form y = a(x − h)² + k has vertex (h, k). a > 0 opens up (minimum); a < 0 opens down (maximum).
  • For x² + bx + c = 0: sum of solutions = −b, product = c.
  • Exponents: xa·xb = xa+b; (xa)b = xab; x−a = 1/xa; xm/n = ⁿ√(xm).
  • Exponential models: y = a(1 + r)t for growth, a(1 − r)t for decay. "Doubles every 3 years" → a(2)t/3. A base of 0.95 means a 5% decrease each period.
  • Function notation: f(x + 1) means replace every x with (x + 1).
Example: quadratic features

f(x) = x² − 4x − 5. Find the zeros and the minimum value.

Show solution

Factor: (x − 5)(x + 1), so the zeros are 5 and −1. The vertex is halfway between: x = 2. f(2) = 4 − 8 − 5 = −9, the minimum (the parabola opens up because a = 1 > 0).

Example: exponential growth

A town of 12,000 people grows 5% per year. Write a model and find the population after 2 years.

Show solution

P(t) = 12,000(1.05)t. P(2) = 12,000 × 1.1025 = 13,230.

3. Problem-Solving and Data Analysis (≈20%)

  • Percent change = (new − old) / old × 100. A 20% increase then a 20% decrease is ×1.2 × 0.8 = 0.96 (a 4% net drop).
  • Reverse percent: after a 15% discount the price is 85% of the original, so original = sale price ÷ 0.85.
  • Units: write units in your work and cancel them like fractions. 1 ft² = 144 in² (not 12).
  • Mean = sum ÷ count (a new value changes the sum). Median = middle value in order. Outliers affect the mean more than the median. Standard deviation = spread around the mean (more spread → larger SD). Range = max − min.
  • Probability = favorable ÷ total. For "given that" (conditional) questions, the total is just the group named in the condition: use one row or column of the table.
  • Samples: results apply only to the population that was randomly sampled. A margin of error gives a plausible range. Only a randomized experiment can show cause and effect.
  • Scatterplots: the slope of the line of best fit is the predicted change in y per 1 unit of x.
Example: back-to-back percents

A $40 shirt is marked up 30%, and then the new price is discounted 10%. What is the final price?

Show solution

$40 × 1.30 × 0.90 = $46.80. (Not 40 × 1.20 = $48. Percent changes multiply, they don't add.)

4. Geometry and Trigonometry (≈12.5%)

  • Angles on a line add to 180°; around a point, 360°; in a triangle, 180°. Vertical angles are equal. Parallel lines cut by a transversal make equal corresponding and alternate angles.
  • Similar triangles: sides are proportional. If lengths scale by k, areas scale by k² and volumes by k³.
  • Right triangles: Pythagorean theorem; common triples 3-4-5, 5-12-13, 8-15-17, 7-24-25; special triangles 30-60-90 (x, x√3, 2x) and 45-45-90 (s, s, s√2).
  • SOH-CAH-TOA: sin = opposite/hypotenuse, cos = adjacent/hypotenuse, tan = opposite/adjacent. sin x° = cos(90° − x°).
  • Circles: area πr², circumference 2πr. Arc length = (angle/360) × 2πr. Equation (x − h)² + (y − k)² = r² has center (h, k) and radius r. Complete the square if the equation isn't in this form.
Example: circle equation

What is the radius of the circle x² + 6x + y² − 4y = 12?

Show solution

Complete the square: (x² + 6x + 9) + (y² − 4y + 4) = 12 + 9 + 4, so (x + 3)² + (y − 2)² = 25. Center (−3, 2), radius 5.

Example: trig

In right triangle ABC with the right angle at C, AC = 8 and AB = 17. What is tan A?

Show solution

BC = √(17² − 8²) = √225 = 15. tan A = opposite/adjacent = BC/AC = 15/8.
